# 任务描述
为招聘系统后端添加ayrshare平台的JWT生成功能，便于用户配置ayrshare平台上linked的社交媒体账号。需要实现两个核心功能：
1. 根据从Nacos配置中心获取的apiKey和privateKey生成JWT链接
2. 根据apiKey获取当前linked的平台信息

# 背景信息
ayrshare是一个社交媒体管理平台，允许用户通过API发布内容到多个社交媒体平台。当前系统已有基础的ayrshare集成（AyrShareService），但缺少JWT生成和平台信息管理功能。系统需要：
- 从Nacos配置中心获取ayrshare的apiKey和privateKey
- 生成JWT链接用于授权社交媒体账号
- 查看当前已连接的社交媒体平台信息
- 提供安全的API接口，需要登录态和权限验证

# 任务分析
- **ayrshare-token** 的目的：为管理员提供便捷的ayrshare社交媒体账号配置和管理功能。
- 识别的问题，包括：
  - **功能需求**：
    1. JWT生成接口：根据Nacos配置的apiKey和privateKey生成JWT授权链接
    2. 平台信息获取接口：根据apiKey获取当前已连接的社交媒体平台列表
    3. 配置管理：从Nacos配置中心动态获取配置信息
  - **数据模型**：
    - 需要创建AyrShare JWT生成请求和响应的DTO类
    - 需要创建平台信息响应的DTO类
    - 需要创建Nacos配置类用于获取apiKey和privateKey
  - **实体关系**：
    - 识别涉及的主要业务实体：
      - AyrShare配置实体：从Nacos获取的apiKey、privateKey等配置信息
      - 用户实体：系统现有的用户实体，用于权限控制
      - 社交媒体平台实体：表示已连接的社交媒体平台信息
    - 分析实体间的关系类型：
      - 用户与AyrShare配置：多对一关系（多个用户可以访问同一个全局配置）
      - AyrShare配置与社交媒体平台：一对多关系（一个配置可以连接多个平台）
    - 确认关系字段和约束条件：
      - 用户权限作为访问控制条件
      - apiKey作为平台连接的唯一标识符
      - 配置信息需要有效的登录态和权限验证
    - 说明关系在业务功能中的体现：
      - 用户登录后可以根据权限访问ayrshare功能
      - 配置信息全局共享，通过权限控制访问
      - JWT生成和平台信息获取与用户权限绑定
- 造成的问题：
  - 缺少JWT生成和平台信息获取的API接口
  - 无法从Nacos动态获取ayrshare配置
  - 缺少权限控制和安全验证
- 为何需要解决：
  - 提升管理员体验，简化社交媒体账号配置流程
  - 支持动态配置管理，无需重启服务
  - 为后续社交媒体发布功能提供基础
- 实施细节和目标：
  1. 创建AyrShareTokenController类，提供JWT生成和平台信息获取接口
  2. 创建AyrShareTokenDomainService类，实现JWT生成和API调用逻辑
  3. 创建相关DTO类用于数据传输
  4. 创建Nacos配置类获取apiKey和privateKey
  5. 添加权限认证注解，确保接口安全
  6. 参考ayrshare官方API文档实现功能
- 其它有用的参考信息：
  - ayrshare JWT生成文档：https://www.ayrshare.com/docs/apis/profiles/generate-jwt
  - ayrshare用户详情文档：https://www.ayrshare.com/docs/apis/user/profile-details
  - 项目现有JWT工具类：JwtUtils
  - 项目现有权限注解：@Auth
  - 项目现有Nacos配置模式：@ConfigurationProperties + @RefreshScope

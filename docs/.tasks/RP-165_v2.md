# 任务描述
实现历史职位复用功能，允许HR在新增招聘需求时复用过往职位。包含两个核心功能：1）历史职位下拉接口（支持ES搜索、分页，最多显示20条，根据jobTitle去重，按id倒序）；2）根据选择的job返回指定字段的详情接口。

# 背景信息
参考需求 https://jira.logisticsteam.com/browse/RP-162 的2.1部分。HR在创建新职位时，希望能够基于历史已创建的职位作为模板，通过4个步骤完成职位复用：Step1获取历史职位列表→Step2选择模板→Step3加载历史job字段供编辑→Step4进入字段编辑。

# 任务分析
- RP-165 的目的：实现历史职位复用功能，提高HR创建职位的效率，减少重复输入工作
- 识别的问题，包括：
  - 功能需求：
    - 历史职位下拉接口：根据当前登录人companyCode查询job数据，最多20条，支持搜索
    - 使用UserContextUtil.getCurrentUserRecruitNeedLogin()获取登录信息
    - 接口接受分页数据和搜索内容，封装到RequestDTO中
    - 底层使用ES模糊搜索，根据jobTitle去重，按id倒序，只返回id和title字段
    - 职位详情接口：根据jobId返回指定字段（jobTitle、modeId、modeName、typeId、typeName、jobDetail、mainDuty、minimumJobRequirement、preferredJobRequirement、skills、benefits、salaryType、salaryTypeName、currency、currencySimpleDesc、customQuestions）
  - 数据模型：
    - 主实体：JobEntity (r_job表)
    - ES实体：JobEsEntity (用于搜索)
    - 关键字段：id, title, companyCode, jobDetail, mainDuty, minimumJobRequirement, preferredJobRequirement, skills, benefits, salaryType, currency, customQuestions等
  - 实体关系：
    - 识别涉及的主要业务实体：User(用户)、Company(公司)、Job(职位)、JobEsEntity(ES职位索引)
    - 分析实体间的关系类型：
      - User与Company：多对一关系（多个用户属于一个公司，通过companyCode关联）
      - Company与Job：一对多关系（一个公司可以有多个职位，通过companyCode关联）
      - Job与JobEsEntity：一对一关系（每个职位在ES中有对应的索引记录，通过id关联）
    - 确认关系字段和约束条件：
      - User.companyCode = Company.companyCode（用户必须属于有效公司）
      - Job.companyCode = Company.companyCode（职位必须属于有效公司）
      - Job.id = JobEsEntity.id（职位与ES索引一一对应）
      - Job.deleted = false（只查询未删除的职位）
      - ES搜索需要根据jobTitle去重，避免重复数据
    - 说明关系在业务功能中的体现：
      - 用户登录后，通过companyCode过滤只能看到自己公司的职位
      - 历史职位搜索基于当前用户的companyCode进行权限控制
      - ES搜索时需要同时过滤companyCode、deleted状态，并根据jobTitle去重
      - 按id倒序排列，确保最新创建的职位优先显示
- 造成的问题：
  - HR创建新职位时需要重复输入大量相同或相似的信息
  - 缺乏历史职位模板功能，工作效率低下
  - 没有便捷的职位复用机制
- 为何需要解决：
  - 提高HR工作效率
  - 减少重复性工作
  - 提升用户体验
  - 标准化职位创建流程
- 实施细节和目标：
  - 新增两个API接口：历史职位列表接口和职位详情获取接口
  - 利用现有的ES搜索能力实现模糊搜索和去重
  - 基于用户权限（companyCode）进行数据过滤
  - 支持分页和搜索功能
  - 实现按id倒序排列
  - 确保只返回必要字段，优化性能
- 其它有用的参考信息：
  - 现有JobController已有相关接口可以参考
  - JobEsService已实现ES搜索功能
  - UserContextUtil提供用户上下文获取功能
  - 需要新增支持jobTitle去重的ES查询逻辑

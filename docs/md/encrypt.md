# 招聘系统非对称加密解密方案设计
## 业务场景


在招聘系统中，需要保护以下敏感数据的传输安全：前端公钥加密后端私钥解密：
- 用户密码: 候选人注册、招聘者登录密码
- 银行卡号: 薪资支付、费用结算
- 邮箱地址: 候选人邮箱、招聘者邮箱
- 手机号码: 候选人联系方式
- 身份证号: 候选人身份验证
- 地址信息: 候选人详细地址

##  技术要求


使用RSA非对称加密算法
- 不同敏感字段使用独立密钥对
- 密钥对存储在Nacos配置中心
- 前端持有公钥，后端持有私钥
- 使用Java代码一次性生成密钥对 多次运行生成不同密钥对
- 封装成独立工具类，不随项目启动自动运行
- 生产环境可用，高效且安全

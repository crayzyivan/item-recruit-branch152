# 历史职位复用
HR 在新增招聘需求时，可复用过往职位。 需求参考 https://jira.logisticsteam.com/browse/RP-162 的2.1部分

## 根据当前登录人的companyCode信息查询job数据 下拉接口
历史职位下拉最多显示 20 条，支持搜索。返回jobId和job title 

## 具体步骤
- Step1：用户从下拉接口中获取到20条数据；
- Step2：若选择一个job作为Template，则下拉显示历史已创建的职位(支持输入前端搜索)；
- Step3：选定某一个历史job后点击下一步，加载历史job对应字段，用户可编辑；
- Step4：点击 Next 进入下一步字段编辑。

## 需要增加的内容

### 获取历史job列表
- 登录信息从UserContextUtil.getCurrentUserRecruitNeedLogin()中获取
- 接口接受分页数据以及搜索内容 封装到一个RequestDTO中
- 支持搜索 底层使用es模糊搜索 根据jobTitle去重 按照id倒序 只返回id和title字段
- 支持分页
- 返回jobId和jobTitle

### 根据选择的job 返回指定的字段
- 根据jobId返回指定job的字段
- 返回内容包括jobTitle、modeId、modeName、typeId、typeName、jobDetail、mainDuty、minimumJobRequirement、preferredJobRequirement、skills、benefits、salaryType、salaryTypeName、currency、currencySimpleDesc、customQuestions
